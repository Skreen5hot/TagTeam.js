TagTeam.js

Natural language to JSON-LD semantic graphs. One script tag. No server.

1. Include the bundle

One file. Models are embedded. No fetch, no setup.

<script src="tagteam.js"></script>

2. Parse text into a semantic graph

const graph = TagTeam.buildGraph("The agent arrested the suspect at the border.");
console.log(JSON.stringify(graph, null, 2));

Returns a JSON-LD graph with entities, acts, roles, and discourse referents.

3. Enrich with your own ontology

Load a Turtle ontology and pass it to buildGraph(). Tier 2 entities get ontologyMatch annotations in the same call.

// Load ontology from a TTL string
const tagger = TagTeam.OntologyTextTagger.fromTTL(ttlString, {
  propertyMap: { keywords: 'rdfs:label', label: 'rdfs:label' }
});

// Parse + enrich in one call
const graph = TagTeam.buildGraph("Patient has fever and cough", {
  ontology: tagger,
  ontologyThreshold: 0.5   // optional, default 0.5
});

// Tier 2 entity nodes now carry ontologyMatch metadata:
// {
//   ontologyMatchClass: "ex:Fever",
//   ontologyMatchConfidence: 0.85,
//   ontologyMatchEvidence: "Fever",
//   ontologyMatchLabel: "Fever"
// }

4. Complete working example

Copy this into an HTML file alongside tagteam.js:

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
</head>
<body>
  <script src="tagteam.js"></script>
  <script>
    // Basic parse
    var graph = TagTeam.buildGraph("The doctor treated the patient.");
    document.write("<pre>" + JSON.stringify(graph, null, 2) + "</pre>");

    // With ontology enrichment
    var ttl = [
      '@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .',
      '@prefix ex: <http://example.org/med#> .',
      'ex:Doctor a rdfs:Class ; rdfs:label "Doctor" .',
      'ex:Patient a rdfs:Class ; rdfs:label "Patient" .'
    ].join('\n');

    var tagger = TagTeam.OntologyTextTagger.fromTTL(ttl, {
      propertyMap: { keywords: 'rdfs:label', label: 'rdfs:label' }
    });
    var enriched = TagTeam.buildGraph("The doctor treated the patient.", {
      ontology: tagger
    });
    document.write("<pre>" + JSON.stringify(enriched, null, 2) + "</pre>");
  </script>
</body>
</html>

API

TagTeam.buildGraph(text, options?)        // returns JSON-LD graph
TagTeam.toJSONLD(text, options?)          // alias for buildGraph
TagTeam.OntologyTextTagger.fromTTL(ttl, config)  // create tagger from Turtle

Options:

  • ontology — an OntologyTextTagger instance for ontology enrichment
  • ontologyThreshold — minimum confidence for matches (default: 0.5)
  • useLegacy — use legacy pipeline (default: false)
