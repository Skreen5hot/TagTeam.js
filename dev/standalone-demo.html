Advanced: Custom Ontology Class Matching

TagTeam includes OntologyTextTagger — load any Turtle/TTL ontology and match text against its classes. Pass { ontology: tagger } to buildGraph() for native enrichment.

// 1. Load a TTL ontology string (keywords maps evidence terms)
const tagger = TagTeam.OntologyTextTagger.fromTTL(ttlString, {
  propertyMap: { keywords: 'rdfs:label', label: 'rdfs:label' }
});

// 2. Build graph with native ontology enrichment (one call)
const graph = TagTeam.buildGraph("Patient has fever and cough", {
  ontology: tagger,
  ontologyThreshold: 0.5  // optional, default 0.5
});
// Tier 2 entity nodes now have ontologyMatch annotations:
// { ontologyMatchClass: "ex:Fever", ontologyMatchConfidence: 0.9, ... }

Key classes:

  • TagTeam.OntologyTextTagger — main tagger (static .fromTTL())
  • TagTeam.TurtleParser — lightweight TTL parser
  • TagTeam.OntologyManager — unified JSON + TTL loading with cache
  • TagTeam.PropertyMapper — configurable property-to-tag mapping
