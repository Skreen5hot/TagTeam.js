Advanced: Custom Ontology Class Matching

TagTeam includes OntologyTextTagger — load any Turtle/TTL ontology and match text against its classes. No values layer needed.

// 1. Load a TTL ontology string
const tagger = TagTeam.OntologyTextTagger.fromTTL(ttlString, {
  propertyMap: {
    keywords: 'myns:keywords',
    label: 'rdfs:label'
  }
});

// 2. Tag text against ontology classes
const matches = tagger.tagText("Patient has fever and cough");
console.log(matches);
// → [{ classIRI: 'myns:Fever', label: 'Fever', score: 0.9, ... }, ...]

// 3. Or build a graph and match post-hoc
const graph = TagTeam.buildGraph("The doctor examined the patient");

Key classes:

  • TagTeam.OntologyTextTagger — main tagger (static .fromTTL())
  • TagTeam.TurtleParser — lightweight TTL parser
  • TagTeam.OntologyManager — unified JSON + TTL loading with cache
  • TagTeam.PropertyMapper — configurable property-to-tag mapping
