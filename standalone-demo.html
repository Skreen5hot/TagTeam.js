TagTeam.js

Natural language to JSON-LD semantic graphs. One script tag. No server.

1. Include the bundle

One file. Models are embedded. No fetch, no setup.

<script src="tagteam.js"></script>

2. Parse text into a semantic graph

const graph = TagTeam.buildGraph("The agent arrested the suspect at the border.");
console.log(JSON.stringify(graph, null, 2));

Returns a JSON-LD graph with entities, acts, roles, and discourse referents.

3. Enrich with your own ontology

Load a Turtle ontology and pass it to buildGraph(). Tier 2 entities get ontologyMatch annotations in the same call.

const tagger = TagTeam.OntologyTextTagger.fromTTL(ttlString, {
  propertyMap: { keywords: 'rdfs:label', label: 'rdfs:label' }
});

const graph = TagTeam.buildGraph("Patient has fever and cough", {
  ontology: tagger,
  ontologyThreshold: 0.2   // optional, default 0.2
});

4. API

TagTeam.buildGraph(text, options?)                   // returns JSON-LD graph
TagTeam.toJSONLD(text, options?)                     // alias for buildGraph
TagTeam.OntologyTextTagger.fromTTL(ttl, config)     // create tagger from Turtle

Options:

  • ontology — an OntologyTextTagger instance for ontology enrichment
  • ontologyThreshold — minimum confidence for matches (default: 0.2)
  • useLegacy — use legacy pipeline (default: false)
